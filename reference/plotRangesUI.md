# Plot Ranges UI

Plot Ranges UI

## Usage

``` r
plotRangesUI(id, title = "Ranges", titleTag = "h4", initRanges = deprecated())
```

## Arguments

- id:

  module id

- title:

  (character) module title

- titleTag:

  (character) HTML tag to put around the title, e.g. "h4" for `h4` from
  `htmltools`

- initRanges:

  (Deprecated) This parameter is no longer needed and has no effect.

## Value

tagList
