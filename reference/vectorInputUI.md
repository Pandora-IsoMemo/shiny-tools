# Vector Input UI

Vector Input UI

## Usage

``` r
vectorInputUI(id, newValueRange, title = NULL, titleTag = "strong")
```

## Arguments

- id:

  module id

- newValueRange:

  (numeric) Range of values that can be entered in the numeric input
  field

- title:

  (character) module title

- titleTag:

  (character) HTML tag to put around the title, e.g. "h4" for `h4` from
  `htmltools`

## Value

tagList
