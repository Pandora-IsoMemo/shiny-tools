# Legend Theme Of GGplot

Apply theme settings for legend to a ggplot object.

## Usage

``` r
setLegendThemeOfGGplot(plot, legend, ...)
```

## Arguments

- plot:

  (ggplot)

- legend:

  (list) named list with style definitions, or output of
  `plotLegendServer`

- ...:

  (list) arguments for `theme`
