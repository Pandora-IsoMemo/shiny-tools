# Add custom points to a ggplot.

Add custom points to a ggplot.

## Usage

``` r
addCustomPointsToGGplot(plot, custom_points)
```

## Arguments

- plot:

  (ggplot) A ggplot object.

- custom_points:

  (list) named list with point definitions, output of
  `customPointsServer`

## Value

A ggplot object with custom points added.
